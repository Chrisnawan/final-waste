# ♻️ NodeWaste - Streamlit Application

Aplikasi web berbasis Streamlit yang dirancang untuk menjalankan model klasifikasi/deteksi NodeWaste secara interaktif. Aplikasi ini dapat dijalankan secara lokal maupun diakses langsung melalui Streamlit Community Cloud.

---

## 📁 Struktur Repositori

Berdasarkan berkas proyek, berikut adalah struktur repositori ini:
* **`app.py`** - File utama aplikasi web Streamlit.
* **`requirements.txt`** - Daftar library Python yang dibutuhkan untuk menjalankan aplikasi.
* **`runtime.txt`** - Spesifikasi versi Python yang digunakan oleh Streamlit Cloud.
* **`fix_model.py`** - Skrip pembantu untuk memuat atau memperbaiki konfigurasi model.
* **`model.weights.h5`** - File bobot (weights) dari model Deep Learning yang digunakan.
* **`class_names.txt`** - Daftar label atau nama kelas objek yang digunakan oleh model.
* **`[5] Csv/`** - Folder penyimpanan data atau aset dalam format CSV.
* **`gambar/`** - Folder untuk menyimpan aset gambar pendukung aplikasi.
* **`Laporan Komprehensif NodeWaste.pdf`** - Dokumen laporan lengkap mengenai proyek ini.
